# PMP Daily Website

Static first-pass website for PMP Daily at `pmpdaily.org`.

## Files

- `index.html` - the page content and structure
- `answers.html` - coming-soon answer library page
- `exam-simulator/` - free 30-question timed PMP exam simulator
- `submit-question.html` - member question submission page
- `privacy.html` - privacy policy draft
- `terms.html` - terms and trademark notice draft
- `styles.css` - responsive styling
- `assets/pmp-daily-logo-cropped.png` - website logo
- `assets/favicon.png` - favicon generated from the logo
- `assets/pmp-daily-hero.png` - generated hero image used by the landing page

## GitHub Pages

Upload these files to a GitHub repository and enable Pages from the repository settings.

The included `CNAME` file is set to `pmpdaily.org`, and `.nojekyll` is included for GitHub Pages compatibility.

For a custom domain, add the domain in GitHub Pages settings and place the required DNS records in Cloudflare. Cloudflare Email Routing can forward inbound-only mail such as `contact@pmpdaily.org` to Gmail.
